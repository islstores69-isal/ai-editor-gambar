Tentang Integrasi Engine Gemini AI:

Aplikasi ini berjalan dalam dua opsi pemrosesan gambar:

  • Mode Demo Lokal: Berjalan luring/tanpa server. Menggunakan algoritma Canvas HTML5 untuk merekonstruksi, memotong, dan menempatkan foto secara estetik pada studio virtual yang Anda pilih. Sangat stabil dan bebas biaya.
  • Gemini AI Live: Mengirimkan prompt serta data gambar Anda langsung ke API `gemini-2.5-flash-image-preview` milik Google untuk regenerasi berbasis kecerdasan buatan sesungguhnya.

Dapatkan API key Anda secara gratis di Google AI Studio.
